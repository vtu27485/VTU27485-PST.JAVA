# VTU27485 Java Programming - Complete Coursework

A unified repository containing all Java programming assignments across multiple weeks and syllabus tasks.

## 📁 Repository Structure

```
├── Week1/          - Week 1 Java Tasks (Tasks 2-10)
├── Week2/          - Week 2 Java Programming (Arrays, Collections, etc.)
├── Week3/          - Week 3 Java Programming Tasks
├── SyllabusTask/   - Official Syllabus Tasks with outputs
└── README.md       - This file
```

## 📚 Contents

### Week 1
Basic Java programming tasks covering fundamental concepts:
- Task 2-10: Basic operations, control flow, and object-oriented programming

### Week 2
Intermediate Java programming with data structures and algorithms:
- Array from Permutation
- Shuffle in Array
- Remove Element
- Remove Duplicates
- Maximum Subarray (Dynamic Programming)
- Highest Altitude
- Group Anagrams
- Top K Frequent Elements
- Java Deque
- Java HashSet

### Week 3
Advanced Java programming concepts and applications

### Syllabus Tasks
Official course syllabus assignments with:
- Task definitions (Syllabus_Tasks1.txt, Syllabus_Tasks2.txt, Syllabus_Tasks3.txt)
- Expected outputs (PNG screenshots)

## 🚀 Getting Started

1. Clone this repository:
```bash
git clone https://github.com/vtu27485/VTU27485-PST.JAVA.git
cd VTU27485-PST.JAVA
```

2. Navigate to the week/task folder you want to review:
```bash
cd Week1
# or
cd Week2
# or
cd SyllabusTask
```

3. Open the .java files in your IDE or text editor

## 📝 File Organization

- **Week1**: `psu java task [2-10].java`
