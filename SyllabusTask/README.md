# Syllabus Tasks - Official Course Assignments

This folder contains official course syllabus tasks with task descriptions and expected outputs.

## Files Included

### Task Definitions
- **Syllabus_Tasks1.txt** - First set of syllabus tasks
- **Syllabus_Tasks2.txt** - Second set of syllabus tasks
- **Syllabus_Tasks3.txt** - Third set of syllabus tasks

### Expected Outputs
- **Syllabus_task1_output.png** - Screenshot of expected output for Task 1
- **Syllabus_task2_output.png** - Screenshot of expected output for Task 2
- **Syllabus_task3_output.png** - Screenshot of expected output for Task 3

## How to Use

1. Read the task description in the .txt file
2. Review the expected output in the corresponding .png file
3. Implement the Java solution
4. Verify your output matches the expected output

## Notes

- All tasks are based on official course curriculum
- Output screenshots provide visual reference for correct implementation
- Tasks build upon each other progressively
