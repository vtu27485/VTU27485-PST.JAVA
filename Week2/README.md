# Week 2 - Intermediate Java & Data Structures

This folder contains Week 2 Java programming tasks focusing on data structures and algorithms.

## Tasks Overview

1. Array from Permutation
2. Shuffle in Array
3. Remove Element
4. Remove Duplicates
5. Maximum Subarray (Dynamic Programming)
6. Highest Altitude
7. Group Anagrams
8. Top K Frequent Elements
9. Java Deque
10. Java HashSet

## Topics Covered

- Array manipulation
- Sorting algorithms
- Hash tables and HashMaps
- Queue and Deque data structures
- Dynamic programming
- String algorithms (anagrams, grouping)
- Frequency counting

## How to Run

1. Open any file in your IDE
2. Compile: `javac filename`
3. Run: `java filename`

## Learning Outcomes

By completing Week 2 tasks, you will understand:
- Advanced array operations
- Collection Framework in Java
- Problem-solving with efficient algorithms
- Data structure selection for different scenarios
